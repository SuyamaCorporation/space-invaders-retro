# 23 - スペースインベーダーリトロ

**ビルド日**: 2026-11-03
**カテゴリ**: fun
**slug**: space-invaders-retro

## 概要
8ビット風スペースインベーダー。3列8行のインベーダーを撃墜しながらレベルを上げていくレトロゲーム。

## 機能
- Canvasベースのレトロスタイルゲーム
- ←→キーで移動、スペース/Zキーで発射
- 3行×8列のインベーダー（行ごとに色分け・2フレームアニメ）
- インベーダーは壁に当たると降下、レベルアップで加速
- 4基の防衛シールド（被弾でHPが低下・色が暗くなる）
- ライフ3つ、0でゲームオーバー
- スコア・ハイスコアをlocalStorageに保存
- 全撃墜でレベルアップ（速度増加）
